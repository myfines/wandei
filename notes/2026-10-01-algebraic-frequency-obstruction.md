# Algebraic-frequency obstruction for sampled Collatz return schedules

Status: conditional on the López--Stoll 2021 critical-density theorem for rational 2-adic non-cyclic trajectories. This is a reduction/exclusion principle, not a Collatz proof.

Sample a Terras orbit at successive visits to residue 2 modulo 9. Let block type r have integer data

\[
(q_r,t_r),
\]

where `q_r` is the number of odd Terras steps and `t_r` the total block length.

Suppose a hypothetical rational 2-adic non-cyclic orbit has a sampled block schedule for which asymptotic block frequencies `f_r` exist, with only finitely many relevant block types, and every `f_r` is algebraic. Then

\[
\bar q=\sum_r f_r q_r,
\qquad
\bar t=\sum_r f_r t_r
\]

are algebraic. Hence, if `\bar t>0`, the limiting ordinary parity density is

\[
\frac{\bar q}{\bar t},
\]

which is algebraic.

López--Stoll (arXiv:2101.12747) prove the following necessary condition: if a rational 2-adic integer has a non-cyclic 3x+1 trajectory, then the lower limiting parity density must equal

\[
\alpha=\frac{\log 2}{\log 3}.
\]

If the sampled block frequencies exist, the parity density limit exists, so it must equal `alpha`.

But `alpha` is transcendental. Indeed, it is not rational, since a rational identity `alpha=p/q` would imply `2^q=3^p`. If `alpha` were algebraic irrational, then Gelfond--Schneider applied to `3^alpha=2` would force `3^alpha` to be transcendental, contradiction.

Therefore

\[
\boxed{\frac{\bar q}{\bar t}\ne\frac{\log2}{\log3}}
\]

whenever `\bar q,\bar t` are algebraic, and such a sampled schedule cannot be the schedule of a rational 2-adic non-cyclic orbit.

## Consequences

1. Any sampled itinerary generated by a primitive substitution on a finite block alphabet is excluded whenever the block frequencies are given by the normalized Perron--Frobenius eigenvector: those frequencies are algebraic, hence so are `\bar q` and `\bar t`.

2. Automatic block schedules with existing rational letter frequencies are excluded a fortiori.

3. More generally, one does not need substitution structure. Any finite-block sampled itinerary with existing algebraic asymptotic frequencies is excluded.

4. Therefore a surviving hypothetical counterexample must leave this low-complexity regime in at least one of the following ways:
   - use unbounded first-return block lengths;
   - fail to have asymptotic block frequencies;
   - or have genuinely transcendental average block statistics.

This is especially relevant to the exact mod-9 induced map, where long first returns come only from the unique long odd-run family. Thus the remaining symbolic difficulty is concentrated in sparse/unbounded long-run defects rather than finite-alphabet regular schedules.

## Relation to the sampled drift model

For a finite block alphabet, define the mean sampled logarithmic drift

\[
\mu=\sum_r f_r\,(q_r\log_2 3-t_r)
=\bar q\log_2 3-\bar t.
\]

If `\mu<0`, cumulative sampled noncontraction fails. If `\mu>0`, the limiting parity density is strictly above the critical value. The only possible critical case is `\mu=0`, which would force

\[
\log_2 3=\frac{\bar t}{\bar q},
\]

an algebraic number, impossible because `\log_2 3` is transcendental (equivalently, its reciprocal `log 2/log 3` is transcendental).

So every finite-alphabet algebraic-frequency sampled schedule is excluded from all three drift regimes.
