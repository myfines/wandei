# Research checkpoint — 2026-09-28

## Goal

Try to convert the Collatz conjecture into a contradiction for a hypothetical
**smallest positive counterexample** \(N\), using reverse ancestors as hard
constraints rather than only average forward drift.

This note records the corrected first checkpoint. Earlier scratch reasoning
incorrectly allowed the minimum reverse chain to continue through multiples of
3. That is wrong: if \(3\mid x\), then \(x\) has no odd preimage under the
odd-only Syracuse map. The code in this repository handles termination
correctly.

---

## 1. Minimal-counterexample lemma

Let

\[
S(x)=\frac{3x+1}{2^{v_2(3x+1)}}
\]

for positive odd \(x\).

Assume a smallest positive odd counterexample \(N\) exists, and let \(x\) be
any point on its odd-only orbit.

If \(y>0\) is odd and

\[
S^k(y)=x,
\]

then \(y\) is also a counterexample: if \(y\) eventually reached 1, then so
would \(x\). By minimality,

\[
y\ge N.
\]

This is the source of every reverse barrier below.

---

## 2. Reverse affine form

A one-step odd preimage of \(x\) has the form

\[
y=\frac{2^a x-1}{3},
\]

where \(a\ge1\) is chosen so that the numerator is divisible by 3.
For odd \(x\), this automatically gives an odd \(y\), and then

\[
3y+1=2^a x
\]

has exactly \(2\)-adic valuation \(a\).

For a valid reverse exponent word \(a_1,\ldots,a_k\), define

\[
A_k=a_1+\cdots+a_k.
\]

Repeated substitution gives

\[
y_k=\frac{2^{A_k}x-C_k}{3^k},
\]

with \(C_k>0\). One recurrence is

\[
C_0=0,\qquad
C_{j+1}=2^{a_{j+1}}C_j+3^j.
\]

Minimality gives \(y_k\ge N\), so

\[
2^{A_k}x-C_k\ge3^kN.
\]

Since \(C_k>0\),

\[
\boxed{\frac{x}{N}>\frac{3^k}{2^{A_k}}.}
\]

Thus every valid reverse path supplies a necessary lower bound on the height
of \(x\) above the hypothetical minimum \(N\).

## 3. Minimum-exponent reverse branch

For \(x\not\equiv0\pmod3\), the smallest valid exponent is forced by \(x\bmod3\):

\[
a_{\min}(x)=
\begin{cases}
1,&x\equiv2\pmod3,\\
2,&x\equiv1\pmod3.
\end{cases}
\]

Therefore

\[
R_{\min}(x)=
\begin{cases}
(2x-1)/3,&x\equiv2\pmod3,\\
(4x-1)/3,&x\equiv1\pmod3.
\end{cases}
\]

If \(R_{\min}^j(x)\equiv0\pmod3\), the minimum reverse chain stops at that
point.

A residue modulo \(3^m\) determines the first \(m\) minimum-reverse decisions,
unless termination occurs earlier.

---

## 4. Exact \(2^m\) surviving-residue count

Consider any word

\[
(a_1,\ldots,a_m)\in\{1,2\}^m.
\]

The affine form after \(m\) reverse steps is

\[
R^m(x)=\frac{2^A x-C_m}{3^m},
\qquad A=\sum a_i.
\]

For all \(m\) divisions by 3 to be integral we need

\[
2^A x\equiv C_m\pmod{3^m}.
\]

Because \(2^A\) is invertible modulo \(3^m\), this congruence has exactly one
solution

\[
x\equiv C_m\,2^{-A}\pmod{3^m}.
\]

Also, for \(a_j\in\{1,2\}\), divisibility at step \(j\) forces precisely the
required residue modulo 3:

- \(a_j=1\) iff the current state is \(2\bmod3\);
- \(a_j=2\) iff the current state is \(1\bmod3\).

So every binary word is realized by one surviving residue class.
Conversely a residue has a unique minimum-exponent decision at each live step,
so two different words cannot correspond to the same residue.

Therefore the number of unit residue classes modulo \(3^m\) that survive all
\(m\) minimum-reverse steps is exactly

\[
\boxed{2^m}.
\]

Since

\[
\varphi(3^m)=2\cdot3^{m-1},
\]

their exact fraction among units is

\[
\boxed{\left(\frac23\right)^{m-1}}.
\]

This is not a proof of Collatz; it is a structural fact about the reverse tree.

## 5. Extremal all-ones word

For

\[
(a_1,\ldots,a_m)=(1,\ldots,1),
\]

the corresponding residue is

\[
x\equiv-1\pmod{3^m}.
\]

Here \(A_m=m\), so the reverse barrier is

\[
\boxed{\frac{x}{N}>\left(\frac32\right)^m.}
\]

Examples:

| \(m\) | residue mod \(3^m\) | barrier |
|---:|---:|---:|
| 1 | 2 | \(3/2\) |
| 2 | 8 | \(9/4\) |
| 3 | 26 | \(27/8\) |
| 4 | 80 | \(81/16\) |
| 5 | 242 | \(243/32\) |

For an actual odd integer in the \(26\bmod27\) class, e.g. \(53\),

\[
53\to35\to23\to15
\]

under minimum reverse steps, with exponent word \((1,1,1)\). The final 15 is a
multiple of 3, so the chain then terminates.

## 7. Why the next exhaustive search is finite

The true reverse tree is larger than the minimum-exponent branch.
If \(a_{\min}\) is valid, then

\[
a=a_{\min}+2j,\qquad j\ge0
\]

is also valid, so there are infinitely many one-step odd preimages.

But only a finite subset can contribute a *contracting* reverse barrier at a
fixed depth \(k\).

A depth-\(k\) path has barrier

\[
B=\frac{3^k}{2^A}.
\]

For \(B>1\),

\[
A<k\log_2 3.
\]

Thus at fixed \(k\), any path capable of forcing an ancestor below the current
height has bounded total exponent \(A\). Consequently there are only finitely
many candidate exponent words to enumerate, with no arbitrary numerical
cutoff.

This is the next implementation target.
