# Binary critical-defect paths as weighted subset sums

Status: exact algebraic normal form for the first-contraction program. Not a Collatz proof.

Fix a global odd-only time `n` with

\[
h_n=0,
\qquad
h_j=\lfloor jL\rfloor-A_j,
\qquad L=\log_2 3.
\]

For a block of length `ell`, define the relative critical mechanical sums

\[
M_j=\lfloor(n+j)L\rfloor-\lfloor nL\rfloor,
\qquad 0\le j\le\ell,
\]

and the local defect heights

\[
g_j=h_{n+j}.
\]

Assume for the moment that the whole block is binary-height:

\[
\boxed{g_j\in\{0,1\}.}
\]

Since `g_0=0`, the local cumulative Syracuse exponent is exactly

\[
\boxed{A'_j:=A_{n+j}-A_n=M_j-g_j.}
\]

## 1. Local transition language

Put

\[
r_j=M_{j+1}-M_j\in\{1,2\}.
\]

Then each actual Syracuse exponent is

\[
\boxed{a_{n+j}=r_j+g_j-g_{j+1}.}
\]

Thus the binary-height path itself determines the exponent word.

The positivity condition `a>=1` gives one immediate forbidden transition:

\[
\boxed{r_j=1,\quad g_j=0,\quad g_{j+1}=1\quad\text{is impossible}.}
\]

The other binary transitions give:

- `0 -> 0`: `a=r`;
- `0 -> 1`: possible only when `r=2`, then `a=1`;
- `1 -> 1`: `a=r`;
- `1 -> 0`: `a=r+1`, so it is `a=2` at `r=1` and the heavy `a=3` repayment at `r=2`.

The existing phase-gate lemma further restricts the last case.

## 2. Affine correction becomes a weighted subset sum

For the local block,

\[
2^{A'_\ell}x_{n+\ell}=3^\ell x_n+d_\ell,
\]

with

\[
d_\ell=\sum_{j=0}^{\ell-1}3^{\ell-1-j}2^{A'_j}.
\]

Substituting `A'_j=M_j-g_j` gives

\[
\boxed{
d_\ell
=\sum_{j=0}^{\ell-1}3^{\ell-1-j}2^{M_j-g_j}.
}
\]

Define the critical mechanical correction

\[
d_{\rm mech}=\sum_{j=0}^{\ell-1}3^{\ell-1-j}2^{M_j}
\]

and weights

\[
w_j=3^{\ell-1-j}2^{M_j}.
\]

Because `g_j` is binary,

\[
2^{-g_j}=1-\frac12g_j.
\]

Therefore

\[
\boxed{
d_\ell
=d_{\rm mech}
-\frac12\sum_{j:g_j=1}w_j.
}
\]

So every height-one defect interval subtracts an explicit positive mechanical weight. Interior defect patterns do not create arbitrary nonlinear corrections: they select a subset of a fixed deterministic weight sequence.

## 3. Boundary-to-boundary blocks have fixed multiplicative coefficient

If the block also ends on the critical boundary,

\[
g_\ell=0,
\]

then

\[
A'_\ell=M_\ell.
\]

Hence every binary defect path with the same start time and length has the same multiplicative coefficient

\[
\frac{3^\ell}{2^{M_\ell}},
\]

and differs from the pure mechanical path only through the weighted subset subtraction above:

\[
\boxed{
2^{M_\ell}x_{n+\ell}
=3^\ell x_n+d_{\rm mech}
-\frac12\sum_{j:g_j=1}w_j.
}
\]

In particular, among binary boundary-to-boundary paths the pure mechanical path maximizes the affine correction and every positive defect lowers the endpoint for a fixed start.

## 4. Modular cylinder form

For a boundary-to-boundary binary block, oddness of the terminal state fixes

\[
3^\ell x_n+d_\ell\equiv2^{M_\ell}\pmod{2^{M_\ell+1}}.
\]

Thus

\[
\boxed{
x_n\equiv
3^{-\ell}\left(
2^{M_\ell}-d_{\rm mech}
+\frac12\sum_{j:g_j=1}w_j
\right)
\pmod{2^{M_\ell+1}}.
}
\]

The search over exponentially many exponent words is therefore equivalent, in the binary-height regime, to a constrained modular weighted-subset-sum problem whose allowed subsets are generated by a two-state automaton.

## 5. Why this is the next computational target

The existing no-35-boundary-run theorem rules out the empty subset over every 35-step window. The remaining hard case consists of frequent short excursions with nonempty subsets.

A useful exact certificate can now be sought with dynamic programming / meet-in-the-middle over:

- the two defect states `g=0,1`;
- the local transition constraint `a>=1`;
- the height-one heavy-repayment phase gate;
- the modular subset sum determining the exact integer cylinder;
- the global admissible height band and eventual descent below `N0`.

This normal form is intended to avoid naive enumeration of all exponent words.
