# Three-shift cocycle on successive 2 mod 9 returns

Status: exact algebraic reduction built on the complete mod-9 first-return classification. This is not a proof of Collatz.

Let

\[
T(n)=\begin{cases}n/2,&n\text{ even},\\(3n+1)/2,&n\text{ odd}\end{cases}
\]

and let

\[
n_0,n_1,n_2,\ldots
\]

be successive visits of one positive Terras orbit to the residue class `2 mod 9`.

For the block from `n_j` to `n_{j+1}`, let

\[
t_j=\text{block length},\qquad q_j=\text{number of odd steps},\qquad
c_j=\frac{3^{q_j}}{2^{t_j}}.
\]

The exact eight-template first-return classification implies a surprisingly small affine correction alphabet.

## Exact three-shift identity

For every first-return block there is

\[
\sigma_j\in\{1,4,16\}
\]

such that

\[
\boxed{
 n_{j+1}+\frac14
 =c_j\,(n_j+\sigma_j).
}
\]

For the six parametric families `E^e O^r E Q`, the shift is `sigma=2^e` with `e in {0,2,4}`. The two exceptional fixed words also fit the same rule:

\[
EO:\quad T^2(n)+\frac14=\frac34(n+1),
\]

\[
EEEO:\quad T^4(n)+\frac14=\frac3{16}(n+4).
\]

Thus all first returns use only the input shifts `1,4,16`, while the output shift is always `1/4`.

Equivalently, if

\[
u_j=n_j+\frac14,
\qquad
d_j=\sigma_j-\frac14,
\]

then

\[
\boxed{
u_{j+1}=c_j(u_j+d_j),}
\]

where

\[
\boxed{
d_j\in\left\{\frac34,\frac{15}4,\frac{63}4\right\}.
}
\]

## Telescoping sampled correction

Define the cumulative principal coefficient

\[
C_J=\prod_{j<J}c_j
=\frac{3^{Q_J}}{2^{T_J}},
\]

where

\[
Q_J=\sum_{j<J}q_j,
\qquad
T_J=\sum_{j<J}t_j.
\]

Dividing the one-block recurrence by `C_{j+1}` gives

\[
\frac{u_{j+1}}{C_{j+1}}
=
\frac{u_j}{C_j}+\frac{d_j}{C_j}.
\]

Hence

\[
\boxed{
\frac{u_J}{C_J}
=
u_0+\sum_{j<J} d_j\frac{2^{T_j}}{3^{Q_j}}.
}
\]

This is a sampled analogue of the usual Collatz/Bernstein correction expansion, but with a three-value correction alphabet.

## The 2-adic identity

Since

\[
u_J=n_J+\frac14=\frac{4n_J+1}{4},
\]

its 2-adic valuation is exactly `-2`. Therefore

\[
v_2\!\left(\frac{u_J}{C_J}\right)
=T_J-2\to+\infty.
\]

Consequently the same telescoping expansion converges in `Q_2` to zero on the left and yields

\[
\boxed{
-\left(n_0+\frac14\right)
=
\sum_{j\ge0}d_j\frac{2^{T_j}}{3^{Q_j}}
\qquad\text{in }\mathbf Q_2.
}
\]

Multiplying by four gives the especially simple finite-digit form

\[
\boxed{
-(4n_0+1)
=
\sum_{j\ge0}\eta_j\frac{2^{T_j}}{3^{Q_j}},
\qquad
\eta_j\in\{3,15,63\},
\quad (\mathbf Q_2).
}
\]

Thus every infinite sampled orbit produces a 2-adic rational value represented by an S-unit series whose coefficient alphabet has only three elements.

## Real convergence on an unbounded orbit

For an unbounded positive orbit, the known bounded-correction / reciprocal-summability mechanism implies that the normalized real correction remains finite. In the sampled identity this means

\[
\sum_{j\ge0}d_j\frac{2^{T_j}}{3^{Q_j}}<\infty
\quad\text{in }\mathbf R.
\]

Because

\[
\frac34\le d_j\le\frac{63}4,
\]

this is equivalent at the sampled level to

\[
\boxed{
\sum_{j\ge0}\frac{2^{T_j}}{3^{Q_j}}<\infty.
}
\]

So a hypothetical unbounded orbit must satisfy two simultaneous requirements:

1. the S-unit series above is a fixed negative rational in `Q_2`;
2. the same positive-term series converges in `R`.

This is a cleaner double-completion formulation than the unsampled correction series.

## Research target

The exponent increments `(t_j,q_j)` are not arbitrary: each is generated by one of only eight first-return templates, and all unbounded combinatorial freedom lies in one odd-run length parameter. A promising next question is therefore:

> Under the first-return template constraints and critical-density constraints, when can a three-digit S-unit series
> \[
> \sum \eta_j 2^{T_j}/3^{Q_j},\qquad \eta_j\in\{3,15,63\},
> \]
> be rational in `Q_2` while its real positive version converges?

Possible tools include p-adic rationality/transcendence criteria, Subspace-Theorem methods for low-complexity expansions, and finite-defect/automatic-word exclusions. The current note only establishes the exact reduction.
