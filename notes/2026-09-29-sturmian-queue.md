# Exact near-Sturmian queue representation — 2026-09-29

## Status

Structural reformulation for a hypothetical least positive counterexample.  It
is not a proof of Collatz.

Let

\[
x_{i+1}=\frac{3x_i+1}{2^{a_i}},\qquad a_i=v_2(3x_i+1),
\]

be the accelerated odd-only orbit of a hypothetical least counterexample
`N=x_0`.  Then every `x_i >= N`.

Define

\[
h_i=\log_2(x_i/N),\qquad
\varepsilon_i=\log_2\left(1+\frac1{3x_i}\right),
\]

\[
\omega=\log_2(3/2),\qquad
E_n=\sum_{i<n}\varepsilon_i,
\]

and

\[
A_n=\sum_{i<n}a_i.
\]

The exact product identity gives

\[
\boxed{
h_n=n(1+\omega)-A_n+E_n.
}
\]

Because `n-A_n` is an integer, the fractional logarithmic height is exactly

\[
\boxed{
\{h_n\}=\{n\omega+E_n\}.
}
\]

Thus the Archimedean phase is an irrational rotation by `omega` with a positive
correction cocycle.

## Queue variables

Put

\[
m_n=\lfloor h_n\rfloor,
\qquad
B_n=A_n-n=\sum_{i<n}(a_i-1),
\]

and

\[
C_n=\lfloor n\omega+E_n\rfloor.
\]

Taking integer parts of the exact height identity yields

\[
\boxed{
m_n=C_n-B_n.
}
\]

Now define the one-step symbols

\[
c_i=C_{i+1}-C_i,
\qquad
b_i=a_i-1.
\]

For a least counterexample `N>1`,

\[
0<\omega+\varepsilon_i<1,
\]

because

\[
\varepsilon_i<\log_2(4/3)=1-\omega.
\]

Hence

\[
c_i\in\{0,1\}.
\]

The orbit therefore obeys the exact integer recursion

\[
\boxed{
m_{i+1}=m_i+c_i-b_i.
}
\]

Interpretation:

- `m_i` is the dyadic altitude band of `x_i/N`;
- `c_i` is an arrival bit generated by a near irrational rotation;
- `b_i=v_2(3x_i+1)-1` is a nonnegative 2-adic service / debit;
- least-counterexample minimality is exactly the hard wall `m_i >= 0`;
- a divergent orbit has `m_i -> infinity` (after excluding periodicity).

This makes the critical drift constraint transparent:

\[
B_n\le C_n
\]

for every prefix.

## Divergent-orbit correction

Classical orbit-sparsity results of Garcia--Tal, together with the standard
dyadic-shell deduction, imply reciprocal summability for an aperiodic divergent
orbit:

\[
\sum_i\frac1{x_i}<\infty.
\]

Consequently

\[
E_n\to E_\infty<\infty.
\]

Therefore

\[
C_n=\lfloor n\omega+E_n\rfloor
\]

has bounded discrepancy from a fixed mechanical/Sturmian carry count

\[
\lfloor n\omega+E_\infty\rfloor.
\]

Equivalently, the arrival process is asymptotically a coding of the irrational
rotation by `omega`, while the debit process is the actual 2-adic valuation
sequence.

The unresolved arithmetic question is whether a **positive integer realizer**
can make these two processes mismatch forever while keeping

\[
m_n=C_n-B_n\ge0
\]

and eventually sending `m_n` to infinity.

## Relation to the current proof frontier

Pure 2-adic dynamics is insufficient: the Collatz map on `Z_2` is conjugate to
the binary shift, so exceptional symbolic sequences exist as 2-adic points.
The positive-integer restriction must supply extra arithmetic rigidity.

Recent formal work on Collatz has isolated a closely related moving-anchor
problem involving powers of two modulo powers of three.  The present queue
representation suggests the same three-way interface:

\[
\boxed{
\text{irrational real rotation}
+\text{2-adic valuation word}
+\text{3-adic realizer / reverse constraints}.
}
\]

A useful next theorem would be a **space-time incompatibility statement**:
no positive-integer valuation word can simultaneously

1. maintain the queue wall `m_n >= 0`;
2. have an escaping queue `m_n -> infinity`;
3. realize the required mod-`2^k` cylinders; and
4. avoid the mod-`3^k` reverse barriers for all depths.

That is the current target rather than further static residue averaging.
